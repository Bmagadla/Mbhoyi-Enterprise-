# Logo — README

**Current logo filename:** `assets/logo.jpg`

The website already references this exact path in the header, About section and footer of `index.html`. The original logo from the website package is included here.

To replace the logo without editing code: export your approved Mbhoyi Enterprise logo as a JPG named **`logo.jpg`**, then replace `assets/logo.jpg` in your GitHub repository. Preserve the spelling and extension, including lowercase letters. If you instead upload a PNG, change all `assets/logo.jpg` references in `index.html` to `assets/logo.png`.

For best results, use a high-resolution logo with enough clear space around it; check the header and footer on a phone after uploading. GitHub Pages may need a short time or a hard refresh to show the updated image.
