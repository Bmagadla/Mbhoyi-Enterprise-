🚀 QUICK START DEPLOYMENT:
───────────────────────────

STEP 1: Enable GitHub Pages (5 minutes)
────────────────────────────────────────
1. Go to: https://github.com/Bmagadla/Mbhoyi-Enterprise-/settings/pages
2. Under "Source", select:
   • Branch: main
   • Folder: / (root)
3. Click Save
4. Wait 2-3 minutes for deployment

STEP 2: Add Custom Domain (5 minutes)
──────────────────────────────────────
1. Still in Settings → Pages
2. Enter custom domain: www.mbhoyienterprises.co.za
3. Click Save
4. GitHub creates CNAME file automatically

STEP 3: Update DNS at Your Registrar (10 minutes)
──────────────────────────────────────────────────
Add this DNS record:
  Host: www
  Type: CNAME
  Value: bmagadla.github.io
  TTL: 3600

STEP 4: Verify and Launch (1-48 hours)
────────────────────────────────────────
1. Wait for DNS propagation (check: whatsmydns.net)
2. Visit: https://www.mbhoyienterprises.co.za
3. Your site goes live! 🎉
